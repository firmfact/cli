# Security

Please report security issues privately, rather than in a public issue:
through GitHub's
[private vulnerability reporting](https://github.com/firmfact/cli/security/advisories/new),
or by email to **security@firmfact.com**. Our disclosure policy is at
https://firmfact.com/security#vulnerability-disclosure.

This covers the CLI in this repository and the firmfact service it talks to.
Only the latest release is supported; `firmfact update` (or your package
manager) gets you there.
